# Escape Run

## Description

Escape Run is a 2D platform game developed using Python and Pygame. The goal of the game is to collect coins, avoid enemies, and reach the exit door to win. Players can move, jump, earn points, and experience sound effects and game-over/win screens.

## Features

* Player movement and jumping
* Coin collection system
* Enemy collision detection
* Score tracking
* Sound effects
* Win and game over screens
* Restart functionality

## Controls

* **Right Shift** - Start the game
* **Left Arrow** - Move left
* **Right Arrow** - Move right
* **Up Arrow** - Jump
* **Space** - Restart after game over
* **Enter** - Exit the game

## Technologies Used

* Python
* Pygame

## How to Run

1. Install Python 3.
2. Install Pygame:

   ```bash
   pip install pygame
   ```
3. Run the game:

   ```bash
   python main.py
   ```
